# Ribbon icons

From [Tabler Icons](https://tabler.io/icons) 3.31.0 (outline), unchanged,
under the MIT license (see `LICENSE`). They draw with `currentColor`; the
GUI substitutes the palette's text colour, so they follow light and dark
themes.

To add one: copy `icons/outline/<name>.svg` from the `@tabler/icons`
package (same version) here.
