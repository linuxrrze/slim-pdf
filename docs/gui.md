# GUI guide

```bash
pdfsigner gui [file.pdf]        # or: pdfsigner-gui [file.pdf]
```

The GUI uses the same certificate profiles as the CLI (see [cli.md](cli.md)).
The screenshots are generated by `scripts/make_screenshots.py`.

## Main window

![Main window with a document open](images/gui-overview.png)

* **Toolbar:** open a file, move between pages (`PgUp`/`PgDown`), and zoom
  (`Ctrl +`/`Ctrl -`, *Fit* = fit width; `Ctrl` + mouse wheel works too).
* **Page:** prepared signature fields appear as boxes:
  * blue, dashed: empty, click to sign it;
  * green: already signed;
  * red: locked by an earlier signature.
* **Sign panel** (right): certificate, appearance options, the current
  target, the **Sign…** button, and a list of all signature fields.

## Placing a new signature

![Placing a signature freely](images/gui-place.png)

1. Pick a certificate.
2. **Click** anywhere on the page. A preview of the signature image appears
   centred on the click.
3. **Drag** it to move it. It always stays inside the page.
4. **Resize** it by dragging the blue corner handle or with `Ctrl` + mouse
   wheel over it. The aspect ratio of the signature image is kept.
5. The panel shows the exact position and size in PDF points.

`Esc` (or *Clear placement*) removes the preview. A placement stays on its
page while you browse other pages.

## Signing a prepared field

![A prepared field selected](images/gui-field.png)

Click an empty field on the page, or in the list on the right. It turns solid
blue and becomes the target. The stamp is fitted into the field's rectangle.

## Signing

Press **Sign…** (`Ctrl+S`) and choose where to save; the default is
`<name>-signed.pdf`. Depending on the profile, pdfsigner asks for the
passphrase, the token PIN or the KeePass master password:

![Passphrase prompt](images/gui-password.png)

After signing, the signed file is reopened. You can add more signatures right
away, for example with another certificate:

![Two signatures from two certificates](images/gui-signed.png)

In this example only Alice's certificate is in the trust list, so the
*Signatures* list shows her signature as valid and the supervisor's as
untrusted (see [Checking signatures](#checking-signatures)).

If the target field is locked by an earlier signature, pdfsigner warns you
that signing will invalidate that signature, and you can still go ahead.
Documents certified as "no changes allowed" can't be signed again; the status
bar points this out when you open one.

The *Signature image* and *Text* checkboxes switch the stamp to image only or
text only for the next signature.

## Checking signatures

The *Signatures* list on the right validates every signature when a document
is opened:

* green: **valid**;
* orange: **untrusted**, i.e. intact but the certificate doesn't chain to a
  trusted root (e.g. self-signed);
* red: **invalid**, i.e. the content was modified or changed in a way the
  signature doesn't allow.

Click a signature to jump to its page. Double-click it for the full report.
The tooltip shows what the signature covers. Extra trusted roots come from
`trust = [...]` in the config file (see [cli.md](cli.md#check-signatures-pdfsigner-verify)).

## Managing certificates

*Manage…* opens the certificate manager. It edits the same config file as
`pdfsigner certs`, and changes are written when you press **Save**.

* **Add** / **Remove** / **Make default** profiles.
* **Test: unlock and show certificate** unlocks the key and shows its
  subject and validity, which is a quick check that a passphrase or KeePass
  entry is right.

PKCS#12 file, passphrase in the OS keyring (for example KeePassXC via Secret
Service):

![Certificate manager: PKCS#12 profile](images/gui-certs-p12.png)

Certificate and passphrase both stored in a KeePass database, with the `.p12`
as an attachment. The stamp text is empty here, so the stamp shows only the
image:

![Certificate manager: KeePass profile](images/gui-certs-keepass.png)

Smartcard or USB token via PKCS#11:

![Certificate manager: PKCS#11 profile](images/gui-certs-pkcs11.png)

With *OS keyring* selected, a **Store passphrase in keyring…** button
appears. It does the same as `pdfsigner certs set-secret`.

## Keyboard shortcuts

On macOS, use `Cmd` wherever this guide says `Ctrl` (e.g. `Cmd+S`, `Cmd` +
scroll), and `Fn+↑`/`Fn+↓` for `PgUp`/`PgDown`.

| Key | Action |
|---|---|
| `Ctrl+O` | Open PDF |
| `PgUp` / `PgDown` | Previous / next page |
| `Ctrl +` / `Ctrl -` | Zoom in / out |
| `Ctrl` + wheel | Zoom (over the page) or resize (over the signature) |
| `Esc` | Remove the placed signature |
| `Ctrl+S` | Sign |
